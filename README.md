# Competition and Logistic Growth Simulation

Early population simulation project originally developed on a TI-92 Plus calculator in 2022 and later adapted into JavaScript and HTML.

This project explored probabilistic population growth, mutation systems, and creature interaction dynamics through simple rule-based simulation. Inspired by an early fascination with mathematical systems and evolutionary modeling, the simulation was developed independently while experimenting with automation, randomness, and emergent behavior.

The original TI-92 Plus source code was partially lost over time during multiple moves between apartments and homes, but surviving notebook notes, JavaScript adaptations, and reconstructed calculator code preserve much of the original logic and structure.

<br>

## Historical Context

During the COVID lockdown years, I became deeply interested in mathematics, automation, and simulation systems. After experimenting with mathematical automation and discovering evolutionary simulation videos such as Primer’s population modeling work, I began building my own creature simulations on a TI-92 Plus calculator before later adapting them into JavaScript and HTML.

This repository preserves that early work as both a technical artifact and a record of the beginnings of my interest in systems engineering, probabilistic modeling, and computational experimentation.
